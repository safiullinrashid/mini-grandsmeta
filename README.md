# Мини-ГрандСмета

Веб-приложение для расчёта строительно-монтажных работ на 9-этажное здание — упрощённый аналог «ГрандСметы». Работает в браузере, без сервера и установки.

## Возможности

- Справочник работ с нормами (ФЕР) — редактируемый, хранится в браузере
- Таблица сметы: шифр, наименование, объём, норма, коэффициент, цена
- Двухколоночная логика: норматив слева, ручной ввод справа (ручное значение перекрывает норматив)
- Коэффициенты: высота, стеснённость, зимнее удорожание + свои
- Расчёт трудозатрат и стоимости
- Расчёт численности: «срок → сколько людей» и «людей → срок»
- Прогресс по разделам работ (этажи 1–9)
- Экспорт в Excel (.xlsx), CSV, печать, сохранение/загрузка проекта (JSON)

## Открыть

## Источники данных (расценки)

Справочник `data/works.json` содержит **официальные федеральные единичные расценки ФЕР-2001** в базисном уровне цен на 01.01.2000 (редакция, утверждённая Приказом Минстроя России № 876/пр от 26.12.2019, в ред. от 14.10.2021) — категории приложения соответствуют сборникам ФЕР, как в «ГрандСмете».

| Категория | Сборник | Полный текст |
|---|---|---|
| Сборник 1. Земляные работы | ФЕР 81-02-01-2001 | [rags.ru](https://rags.ru/documents/prod/prikaz/8/fer_59844.html), [Минстрой (PDF)](https://files.stroyinf.ru/Data2/1/4293723/4293723624.pdf) |
| Сборник 6. Монолитные конструкции | ФЕР 81-02-06-2001 | [rags.ru](https://rags.ru/documents/prod/prikaz/8/fer_23880.html) |
| Сборник 7. Сборные конструкции | ФЕР 81-02-07-2001 | [rags.ru](https://rags.ru/documents/prod/prikaz/8/fer_38670.html) |
| Сборник 8. Конструкции из кирпича и блоков | ФЕР 81-02-08-2001 | [rags.ru](https://rags.ru/documents/prod/prikaz/8/fer_45625.html) |
| Сборник 11. Полы | ФЕР 81-02-11-2001 | [rags.ru](https://rags.ru/documents/prod/prikaz/8/fer_35323.html) |
| Сборник 12. Кровли | ФЕР 81-02-12-2001 | [rags.ru](https://rags.ru/documents/prod/prikaz/8/fer_74499.html) |
| Сборник 15. Отделочные работы | ФЕР 81-02-15-2001 | [rags.ru](https://rags.ru/documents/prod/normativy/0/fer-2_84275.html) |

Официальный федеральный реестр сметных нормативов ведёт Минстрой РФ — [ФГИС ЦС (fgiscs.minstroyrf.ru/frsn)](https://fgiscs.minstroyrf.ru/frsn/fsnb).

Поля расценки:
- `code` — шифр (например, 07-01-029-02);
- `name` — наименование работ;
- `unit` — измеритель (м³, 100 м², 100 шт. и т.д.);
- `basePrice` — прямые затраты (₽/ед. изм., базисный уровень 2000 г.);
- `norm` — затраты труда рабочих, чел.-ч на единицу;
- `category` — сборник ФЕР (раздел сметы);
- `source` — ссылка на полный текст сборника.

> В базе 41 работа по 7 сборникам — этого достаточно для локальной сметы на 9-этажное здание. Полные официальные сборники содержат тысячи расценок; при необходимости их можно добавить через справочник или импорт проекта.

Данные загружаются при первом запуске в браузер (localStorage) и дальше редактируются прямо в интерфейсе: кнопка «Справочник работ».

## Формулы

```
Трудозатраты = (Объём / Ед. изм. в ФЕР) × Норма × Коэффициент
Стоимость   = Объём × Цена × Коэффициент
Людей       = Трудозатраты / (Срок × Часов в смене)
Срок        = Трудозатраты / (Людей × Часов в смене)
```

## Как изменить данные

1. Нажмите «Справочник работ» — прямо в таблице можно менять нормы, цены, названия.
2. Кнопка «+ Новая работа» — добавить расценку.
3. Кнопка «Коэффициенты» — редактировать коэффициенты и создавать свои.
4. «Скачать проект (JSON)» — выгрузить всё, чтобы перенести на другой компьютер.
