# Мини-ГрандСмета — типовая КНС

Веб-приложение для локального расчёта сметы на типовую канализационную насосную станцию (КНС): от планировки площадки и котлована до внутренних трубопроводов, наружной канализации и отделки. Работает в браузере без сервера.

**Онлайн:** https://safiullinrashid.github.io/mini-grandsmeta/

## Что внутри

- **39 официальных расценок ФЕР-2001** по 9 сборникам:
  - 1 — земляные работы;
  - 6 — монолитные бетонные и железобетонные конструкции;
  - 7 — сборные конструкции;
  - 8 — конструкции из кирпича и блоков, гидроизоляция;
  - 11 — полы;
  - 12 — кровли;
  - 15 — отделочные работы;
  - 16 — трубопроводы внутренние;
  - 23 — канализация, наружные сети.
- Ввод объёма в натуральных единицах (м³, м², м, шт.) — стоимость и трудозатраты считаются автоматически.
- **Зарплаты по ролям:** рабочий, машинист, прораб, страховые взносы. Ставки редактируются.
- **Срок и численность:** два понятных режима — «знаю численность → нужен срок» и «знаю срок → нужна численность».
- **Цены и ресурсы** — отдельное окно с вкладками:
  - ставки, индексы, НР/СП;
  - расценки ФЕР (можно править цены и нормы);
  - техника и стоимость аренды;
  - коэффициенты (котлован, стеснённость, зима и т.д.).
- Правки ресурсов **не сбрасывают открытую смету**; при отмене изменения откатываются.
- Экспорт в Excel (.xlsx), CSV, JSON-проект; импорт JSON; печать.
- Автосохранение в браузере (localStorage, ключи `mgs_v3_*`).

## Как считается

### Чел.-ч

```
чел.-ч = объём ÷ делитель единицы × норма чел.-ч на единицу × коэффициент
```

Норма берётся из ФЕР. Например, для бетонной подготовки норма 135 чел.-ч на 100 м³. При объёме 8 м³:

```
8 ÷ 100 × 135 = 10,8 чел.-ч
```

Зарплата рабочего = чел.-ч × ставка рабочего (по умолчанию 450 ₽/чел.-ч).

### Маш.-ч

```
маш.-ч на единицу = оплата труда машиниста по ФЕР ÷ 11 ₽/чел.-ч
маш.-ч = объём ÷ делитель × маш.-ч на единицу × коэффициент
```

Машино-час — это час работы машины, **не объём в м³**. Значение можно переопределить вручную в карточке строки.

### Аренда техники

```
к оплате = max(маш.-ч, 4)
аренда = к оплате × ставка аренды, ₽/маш.-ч
```

Минимум 4 маш.-ч применяется именно к машино-часам, а не к объёму. Аренда считается справочно; переключатель в «Цены и ресурсы» позволяет включить её в итоговую стоимость вместо эксплуатации машин по ФЕР.

### Стоимость по ФЕР

```
прямые = оплата труда × индекс труда
       + эксплуатация машин × индекс машин
       + материалы × индекс материалов
НР = прямые × НР%
СП = прямые × СП%
итого = прямые + НР + СП
```

Индексы, НР и СП — редактируемые ориентировочные значения. Для официальной сметы подставьте действующие индексы Минстроя и нормативы НР/СП по видам работ.

### ФОТ

```
ФОТ рабочих      = чел.-ч × ставка рабочего
ФОТ машинистов   = маш.-ч × ставка машиниста
ФОТ прораба      = (рабочие + машинисты) × процент прораба
страховые взносы = ФОТ × 30,2 %
```

## Запуск

Локально:

```bash
cd mini-grandsmeta
python3 -m http.server 8765
# открыть http://localhost:8765/
```

Можно открыть `index.html` напрямую, но при `file://` браузер блокирует чтение `data/*.json`; приложение возьмёт встроенную копию из `data-embedded.js`.

## Проверка расчётов

```bash
node tests/calc.test.js
```

Тест проверяет нормы ФЕР, чел.-ч и маш.-ч, минимум 4 маш.-ч аренды, ФОТ, НР/СП и расчёт срока/численности.

## Обновление данных

1. Скачайте актуальные сборники ФЕР с [rags.ru](https://rags.ru/documents/prod/fer_federalnye-edinichnye-rascenki/fer_federalnye-edinichnye-rascenki_0.html) или проверьте реестр [ФГИС ЦС](https://fgiscs.minstroyrf.ru/frsn/fsnb).
2. Обновите `data/works.json`, `data/rates.json`, `data/coefficients.json`, `data/meta.json`.
3. Пересоберите офлайн-копию `data-embedded.js` или нажмите «Обновить данные» → «Обновить из data/*.json» на сервере.
4. Альтернатива — «Обновить данные» → «Импортировать JSON» с тем же набором полей.

Прямой `fetch` с rags.ru из браузера блокируется CORS, поэтому в интерфейсе сделаны ссылки на первоисточники, а не автоматическая загрузка с сайта.

## Ограничения

- Материалы, не учтённые расценкой (например, товарный бетон), в ФЕР часто вынесены за пределы строки — проверяйте состав работ.
- НР и СП заданы в процентах от прямых затрат; это упрощение, а не официальная методика.
- Индексы пересчёта ориентировочные и редактируются.
- Смета не заменяет официальную сметную документацию.
