# Мини-ГрандСмета

Веб-приложение для расчёта строительно-монтажных работ на 9-этажное здание — упрощённый аналог «ГрандСметы». Работает в браузере, без сервера и установки.

## Возможности

- Справочник работ с нормами (ФЕР) — редактируемый, хранится в браузере
- Таблица сметы: шифр, наименование, объём, норма, коэффициент, цена
- Двухколоночная логика: норматив слева, ручной ввод справа (ручное значение перекрывает норматив)
- Коэффициенты: высота, стеснённость, зимнее удорожание + свои
- Расчёт трудозатрат и стоимости
- Расчёт численности: «срок → сколько людей» и «людей → срок»
- Прогресс по разделам работ (этажи 1–9)
- Экспорт в Excel (.xlsx), CSV, печать, сохранение/загрузка проекта (JSON)

## Открыть

- Локально: просто открыть `index.html` в браузере
- В интернете: GitHub Pages → https://safiullinrashid.github.io/mini-grandsmeta/

## Структура

```
mini-grandsmeta/
├── index.html          # Главная страница
├── style.css           # Стили
├── script.js           # Логика расчётов
├── data/
│   ├── works.json      # Справочник работ (демонстрационные нормы ФЕР)
│   └── coefficients.json # Стандартные коэффициенты
└── README.md
```

> **Важно.** Данные в `works.json` — демонстрационные (примерные нормы). Они загружаются при первом запуске в браузер (localStorage) и дальше редактируются прямо в интерфейсе: кнопка «Справочник работ». Отредактированный справочник можно сохранить нажатием «Скачать проект (JSON)».

## Формулы

```
Трудозатраты = (Объём / Ед. изм. в ФЕР) × Норма × Коэффициент
Стоимость   = Объём × Цена × Коэффициент
Людей       = Трудозатраты / (Срок × Часов в смене)
Срок        = Трудозатраты / (Людей × Часов в смене)
```

## Как изменить данные

1. Нажмите «Справочник работ» — прямо в таблице можно менять нормы, цены, названия.
2. Кнопка «+ Новая работа» — добавить расценку.
3. Кнопка «Коэффициенты» — редактировать коэффициенты и создавать свои.
4. «Скачать проект (JSON)» — выгрузить всё, чтобы перенести на другой компьютер.
